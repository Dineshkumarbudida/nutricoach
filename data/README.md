# Nutrition data policy

No third-party nutrition dataset is bundled in this repository.

The first import adapter will target USDA FoodData Central because its data are published in the public domain under CC0. This is a legal bootstrap source for foundational ingredients, not a claim that it adequately represents Indian dishes.

Indian Food Composition Tables and Dietary Guidelines for Indians must not be copied into a distributable product unless the required permission has been obtained and recorded. Their publications encourage personal use and dissemination but state that electronic storage or reproduction for creating a product requires prior written permission from ICMR-NIN.

Indian dishes will initially be represented through:

1. User-authored private recipes.
2. Project-authored recipes based on independently sourced, redistributable ingredient data and documented yields.
3. Data imported only after a rights review.

Synthetic fixtures used by tests are not food facts.
