# ADR-0004: License source code under Apache-2.0

**Status:** Accepted provisionally before public contributions  
**Date:** 2026-10-11

## Decision

Use Apache License 2.0 for repository source code because it is OSI-approved, permissive for self-hosting and institutional adoption, and includes an explicit patent grant.

## Boundary

This decision does not license:

- Third-party food-composition data.
- Scientific publications or guideline text.
- Trademarks, images, or packaged-food labels.
- Model weights.
- User-contributed private recipes.

Every distributed non-code asset requires its own rights record.
