# Evidence registry

Scientific evidence is versioned separately from food-composition data.

Each active rule records:

- rule ID
- population
- recommendation or equation
- unit
- effective version
- source title
- DOI or PubMed identifier when available
- evidence type
- certainty/strength
- limitations
- last reviewed date
- reviewer/status

## Current reference families

### Energy

Use the applicable 2023 Dietary Reference Intakes Estimated Energy Requirement equations for adults and age-appropriate equations for other populations when supported by the product's scope.

Source:
Health Canada, Equations to Estimate Energy Requirement.

### Protein

For healthy adults, retain the adult RDA as the general reference. For exercising adults, the product may use an evidence-reviewed sports-nutrition range and must show that it is a planning rule rather than a medical requirement.

Sources:
- Health Canada, Reference Values for Macronutrients.
- Jager et al., International Society of Sports Nutrition Position Stand: protein and exercise.
- Morton et al., systematic review and meta-analysis of protein supplementation and resistance training.

### Fiber

Use 14 g per 1,000 kcal as the planning reference for adults when the product scope supports it.

Source:
Health Canada, Reference Values for Macronutrients.

### Micronutrients

Use the applicable DRI reference for the user's age and sex-related reference category. Do not treat a single-day intake below a reference as a diagnosis.

## Research-update policy

Daily literature surveillance may discover evidence. It does not directly change active rules.

New evidence follows:

literature watch -> screening -> synthesis -> review -> change proposal -> automated tests -> approval -> versioned activation

Historical recommendations preserve the ruleset version that produced them.
