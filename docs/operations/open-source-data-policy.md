# Open-source data policy

Open-source does not mean that arbitrary internet data may be copied into NutriCoach.

## Eligible production sources

A source is eligible when its license clearly permits the intended reuse or the data are public domain, and required attribution and license obligations can be preserved.

Primary sources:

- USDA FoodData Central: CC0/public domain.
- Open Food Facts: ODbL database, with separate image licensing.

## Not eligible without additional rights review

- webpages without reuse rights
- unlabeled datasets
- government publications re-uploaded under a new license without evidence of sublicensing rights
- scraped commercial nutrition data
- images whose rights differ from text/nutrient data

## Indian datasets

Some public repositories compile Indian nutrition data and declare CC0. NutriCoach can inspect them for discovery and validation, but a repository license statement alone does not establish the uploader's rights over an underlying publication. Such sources remain outside the authoritative production bundle until provenance is resolved.

## Reproducibility

Each refresh records:

- source URL
- source release/date
- retrieval date
- source checksum for downloaded files
- ingestion software version
- normalized catalog version
- validation result
