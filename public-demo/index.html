    Current scope

    What this public demo is—and is not

    It demonstrates

    • Deterministic portion scaling.
    • True zero versus missing-data semantics.
    • Bounded and unbounded uncertainty.
    • Transparent assumptions and warnings.
    • A fully client-side, no-account experience.

    It does not yet include

    • A production food or recipe database.
    • User profiles, diaries, targets, or recommendations.
    • Application accounts or multi-user authorization.
    • Medical guidance or individualized nutrition advice.
    • Server-side decimal arithmetic from the Java backend.
